# 0.1.3 公开预览 · 2026-10-21

## 更适合手机的播放流程

- 保留社区 PR 的绿色／浅深色界面和分组思路。三步教程只在首次进入弹出，之后点「指南」重开；工作台不常驻大教程。
- 底部迷你播放条显示当前歌曲，点击进入完整播放器、歌词和当前播放列表。支持顺序、列表循环、单曲循环和随机播放。
- 生成／换一批只更新候选，不暂停、不切歌、不顶掉当前播放列表；「播放这批」才明确交接。清空候选与停止并清空播放列表分开。
- 生成按钮放在随机设置之后；音乐风格与语言折叠，候选入选原因可展开。同步页保留实际可操作的二维码、账号歌单和备份入口。

## 想听与不想听，都能选

- 「本次不听」支持风格、氛围、语言多选硬排除，优先于正向偏好、近期占比、参考强度和重排插件。
- 分类未知默认保留，并明确说明不能据此保证不含被排除风格；可勾选同时排除所选维度的未分类歌曲。
- 近期池先取原范围最近 100 首再排除，不将更早的歌晋升为近期。100% 近期容量不足不拿老歌补齐。
- 长期歌手黑名单在歌曲更多菜单／播放器／当前列表中操作，在「我的 → 黑名单」统一管理。包含署名合唱和以后同步的新歌；优先平台歌手 ID，本地与旧资料缺少 ID 时按完整署名匹配，不做名字包含猜测。
- 歌手屏蔽与单曲黑名单独立，解除歌手屏蔽不取消逐首拉黑，也不自动复原队列。不删除平台歌曲，不推断未署名的幕后作者。

## 通知控制与插件边界

- Android 系统媒体通知增加桌面歌词开关。需要手动开启「歌词与翻译」「Android 桌面歌词」插件，并由本人授权悬浮窗；缺少授权只提示，不绕过权限。
- 网易云开启且当前为平台曲目时才显示官方喜欢操作。读取真实状态、明确目标写入并回读，旧歌曲／旧账号通知、重复点击和插件关闭均有门禁；本地歌曲不写入平台。
- 歌词窗口不增加常驻可点按钮，锁定后全窗穿透；拖动仍是显式 20 秒位置调整，状态变化回传应用内。
- 彩蛋保留为用户自主开关，默认关闭。在「我的 → 功能插件与 DIY」开启后，曲库确认关键词才触发原创动态唱片和小调，可随时退出或关闭。公开包不含个人版的第三方 GIF／商业录音，用户可临时自选素材；不调高系统音量。
- 本地音乐、可控随机仍是核心，网易云默认关闭；MIT 许可与公开版独立包名、存储、签名保留。新增负向规则也可保存为 JSON 预设。

## 验证边界
