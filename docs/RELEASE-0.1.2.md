# 随听 0.1.2 公开预览

新增默认关闭的「搜索彩蛋」插件。到「我的 → 功能插件与DIY」开启，在「我的曲库」搜索“欧耶”或“deepseek／大肥鱼”并回车触发；输入法组词、普通输入与个人主页搜索不会触发。

默认提供 MIT 自有代码生成的动态唱片表情与原创小调，不附带个人版第三方人物 GIF、商业歌曲或录音。支持本次换入本机 GIF／图片（5 MB）和普通音频（40 MB）；文件不上传、不进 JSON 备份，也不持久保存到公开包。自行确认所选素材的使用权限。

曲库已有且未拉黑的对应版本可联动播放；平台查询必须主动点击，且受网易云插件开关、歌曲版本匹配、账号权限与黑名单限制。找不到时保留原创小调或提示改用本机音频，不解锁加密或付费内容。

彩蛋不替换随机队列，不调高系统音量；退出按钮、Esc 和 Android 返回键均可关闭。退出只恢复未变更的原队列。切后台停止彩蛋，不自动恢复原队列；文件选择器切换会暂停音效，保留选择中的窗口。

公开包名仍为 io.suiting.music.publicapp，versionCode 3，versionName 0.1.2-public。沿用公开预览签名，可覆盖安装，建议升级前导出资料。个人版、实验室版与旧公开 APK 均不变。

仍为预览包，Android 悬浮窗、后台播放、文件选择与厂商系统行为未完成设备矩阵验收，不声称已经过实机验收。
