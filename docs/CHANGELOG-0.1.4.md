# 0.1.4 公开预览补丁 · 2026-10-22

在 0.1.3 基础上修复和精简，不是新的大版本，不更换主界面、包名或签名。个人版、QQ 实验室和 UI 实验版独立保留。

## 本轮变化

- **安装包精简**：R8 代码优化与资源裁剪；Android 预览 APK 从约 5.10 MB 降至约 1.1 MB。不删本地导入、随机核心、歌词、通知、插件或原创彩蛋，不转码音频。
- **修复通知按钮变化**：红心不再因网络核对被禁用／从自定义操作中移除；为前后曲保留系统媒体槽位。喜欢、桌面歌词仍是不同命令，保留歌曲、账号、旧通知和状态令牌校验。
- **喜欢先暂存**：网易云曲目的红心写入当前账号的本机持久化日志，通知和应用使用同一份记录，不等待即时远端同步。只有「我的 → 喜欢同步 → 同步到网易云」才提交待办；「只核对，不写入」只读。
- **安全核对**：提交前后读取远端，每批最多 100 首，操作使用明确的喜欢／取消喜欢目标；不清空官方列表，不删除无关歌曲。不确定写入停止本批、保留未确认记录、不自动重试。同步中产生的新本机操作不被旧回包抹掉。
- **今日操作对照**：显示今日本机操作与当前官方状态是否一致。首次检查建立基线，后续显示较上次检查新增；官方接口没有逐首喜欢日期，不声称精确取得“网易云今日新增”。已确认的歌后来在官方客户端修改，只报告差异，不自动强制恢复。
- **队列末尾续播**：顺序队列自然播完从当前列表第一首继续。暂停、停止、空队列与播放错误不触发续播；新生成候选不自动顶掉当前播放队列。原有单曲、列表循环、随机保持。
- **介绍与截图更新**：README 换为 0.1.4 实际工作台及手机深色播放器画面，示例／自制静音音频明确标注，旧界面不再当作当前截图。

## 公开版边界不变

本地音乐和可控随机仍是核心；网易云、桌面歌词和搜索彩蛋按原有插件开关工作，网易云及彩蛋默认关闭。关闭网易云会阻止新平台调用，本地文件仍可独立使用。本地曲目不能暂存或提交为网易云喜欢；无解锁付费、试播、DRM 或加密音频能力。

公开素材仍为原创动态唱片和小调，不加入私人版本的第三方 GIF 或商业录音。MIT 只覆盖自有代码，不覆盖第三方音乐及其他内容。

## 升级与数据

Android `io.suiting.music.publicapp`，versionName `0.1.4-public`，versionCode `5`；沿用公开预览证书，可覆盖原公开预览包，**不要先卸载**。这是优化 release 构建、沿用本地预览签名的包，不是生产商店发行证书。

本机喜欢按账号隔离，覆盖升级保留；退出账号不删除待办，重新登录同一账号可继续。通用歌单 JSON 不包含喜欢日志；卸载／清除应用或站点数据前，请完成手动同步。没有账号授权时不能把离线文件映射为官方喜欢。
