# 随听

**让随机听歌，按你的想法来。**

一款本地音乐优先的 Android 音乐播放器，也提供浏览器开发预览。选择曲库范围、氛围、风格和语言，调好近期新歌与老歌的比例，再生成下一批；不需要连接音乐平台，也能使用核心功能。

当前版本：**0.1.2 公开预览** · Android 8.0+

## 可控随机，而不是随便打乱

- **选择范围**：全部曲库、指定歌单或收藏，不把范围外的歌曲偷偷塞进来。
- **多选氛围与风格**：温柔、轻快、伤感、治愈、浪漫、安静、梦幻、怀旧、热血、躁动、专注、慵懒；风格独立多选。
- **按演唱语言筛选**：中文、日语、韩语、英语、法语、俄语、德语等常用语言及其他；英语是语言分类，不按美国国籍判断。
- **近期与老歌比例**：参考最近加入歌单的100首，调节它们在本批中的占比；100%只从近期池选，0%只从老歌池选，容量不足会说明原因。
- **公平轮换**：参考真实播放记录和近期曝光，不把“算法刚刚放过”直接当成“用户更喜欢”。
- **听感与参考**：调节变化程度、近期口味参考和歌单参考强度；参考歌单不自动扩大候选范围。
- **避免重复**：设置最近听过歌曲的冷却时间，支持全局黑名单与恢复。
- **自己定数量**：预设数量或1–5000首自定义；硬条件不足时返回实际可选数量和说明。
- **整批替换队列**：重新生成不会把新歌追加到旧队列；播放顺序随机与选歌随机相互独立。

## 带上本地音乐

- 使用Android系统文件选择器多选音频，仅保存所选文件的只读授权；不修改、不上传原文件。
- 支持选择MP3、FLAC、M4A、AAC、WAV、OGG、OPUS等普通音频，具体编码能否播放取决于设备。
- 读取文件可提供的歌名、歌手、专辑、风格与语种；支持手工分类和自定义标签，手工标注优先保留。
- 缺少分类时明确显示未知；**没有自动听音或AI分类**，歌单整体标签也不是每首歌的确定分类。
- 本地收藏、曲库搜索、资料JSON备份与恢复；音频、系统文档授权和账号凭据不进入JSON备份。
- 浏览器预览把导入音频副本保存在当前浏览器的IndexedDB，刷新可恢复；它与Android文件授权机制不同。

## 播放与歌词

- 上一首／下一首、暂停与继续、拖动进度。
- 顺序播放、列表循环、单曲循环、随机播放。
- Android原生Media3媒体服务与通知／锁屏控制；不依赖网页计时器维持播放。
- 应用内滚动歌词、当前行高亮、自动跟随开关；可给本地歌曲绑定LRC／TXT。
- 可选Android桌面歌词：位置、对齐、单／双行、翻译、字号、透明度及触摸穿透设置，另需系统悬浮窗权限。
- 本地音质为**原文件**，不转码；连接平台时分别显示请求音质与实际返回信息，不保证设备端无损输出。

## 可选连接网易云

### 第一次使用

1. 在首页点击醒目的「连接网易云音乐」，确认开启连接后进入账号页。导航中的「连接音乐」也可以随时进入。
2. 点击「创建登录二维码」，用手机网易云音乐扫码确认。
3. 展开「我创建的」或「我收藏的」，在需要的歌单旁点击「同步」。同步读取歌单信息，不等于下载音频。
4. 点击「去随机工作台」，选择范围、氛围和歌曲数量，再点「生成随机队列」和「播放」。
5. 「换一批」重新选歌，「换顺序」只改变当前歌曲的顺序。「保存到网易云」可经确认创建一张新歌单。

风格与语言合并在折叠筛选中；近期比例、参考歌单、标签与分类统一放在「精细调频与分类」。不连接网易云也可以在首页直接导入本地普通音频。空曲库时首页只显示开始引导，导入或同步后显示选歌工作台。

默认关闭。在首页点击「连接网易云音乐」主动开启并本人授权后，可使用以下功能；也可以在「我的 → 功能插件与DIY」管理开关：

- 同步账号歌单、我喜欢的音乐与有权限访问的私密歌单。
- 导入歌单链接、读取每日推荐，把喜欢的日推收藏到随听。
- 显式选择“喜欢到网易云”才写入官方红心，与随听本地收藏分开。
- 把符合条件的平台歌曲另存为新的网易云歌单，不修改源歌单。
- 网易云百科分类作为辅助信息，不覆盖手工分类；不在官方曲库的上传歌曲会跳过并提示。

非官方适配，接口可能变化；登录、会员、地区、版权与可播放范围由网易云决定。**不绕过付费、试播或DRM，不提供加密音乐解锁。** 本地歌曲不会按同名歌曲冒充平台ID，也不会被上传到平台。

## 插件与DIY

- **搜索彩蛋**：在「我的 → 功能插件与DIY」开启，曲库输入“欧耶”或“deepseek／大肥鱼”并回车，显示原创动态唱片与小调。默认关闭、不联网、不改变系统音量、不替换队列；有明确退出按钮与 Android 返回键支持。
- **彩蛋素材DIY**：支持本次更换本机 GIF／图片（5 MB 以内）或音频（40 MB 以内），文件不上传、不进入 JSON 备份。公开包不内置个人版的第三方人物 GIF 或商业歌曲；原文件的使用权限由用户确认。
- **对应版本联动**：曲库已有且未拉黑的对应歌曲可播放；主动点“查找网易云对应版本”时，须先开启网易云插件。匹配不到或无权限会提示，不用其他翻唱冒充指定版本。关闭、切后台或退出后停止彩蛋；正常退出只恢复未变更的原队列。

- 网易云连接、本地文件信息、歌词与桌面歌词分别开关；关闭平台不影响本地随机核心。
- 导入JSON随机预设或队列重排扩展，默认关闭；预设手动应用，重排只调整本次已选歌曲。
- 为数据源、元数据、歌词、队列与界面保留版本化源码扩展合同。
- 当前不是任意JS插件商店，也没有默认AI连接。开发者适配需审查、接线、测试并重新打包；不能绕过范围、冷却与黑名单。

示例和接入说明见 [插件开发](PLUGINS.md)。

## 外观与隐私

- 绿色主题，跟随系统／浅色／深色模式，手机与桌面自适应。
- 自制黑胶唱片图标，提供安卓自适应和主题单色资源，见 [图标说明](docs/ICON.md)。
- 可自定义本机头像；个人主页集中管理收藏、黑名单、账号和扩展。
- 默认不连接平台，无广告、分析统计或遥测，不上传本地音频。
- 详细数据处理与系统权限见 [隐私说明](PRIVACY.md)。

## 开发与当前边界

```sh
npm ci
npm test
npm run check
npm start
```

需要Node.js 22+，浏览器预览地址为 `http://127.0.0.1:4392/`。Android构建见 [开发说明](docs/DEVELOPMENT.md)。

目前为预览版，已通过197项JavaScript和37项JVM测试；没有完成Android实机矩阵与真实账号端到端验收。桌面歌词、后台播放和文件跨重启访问请以设备实测为准。加密音频、QQ音乐、任意脚本安装与AI听音分析均不在本版支持范围内。
